Features

KaspaCom Wallet is a browser-based, self-custody wallet built for the Kaspa ecosystem — native KAS, tokens, NFTs and domains, all in one place.

Self-custody by design

Your seed phrase is generated and encrypted on your own device. Nothing is sent to KaspaCom's servers, and no one but you can authorize a transaction. See the FAQ for details on how key storage and recovery work.

Full Kaspa asset support

  • KAS — send, receive and track native Kaspa.
  • KRC-20 tokens — manage fungible tokens built on Kaspa. Read the KRC-20 guide.
  • KRC-721 NFTs — view and manage Kaspa NFT collections.
  • KNS domains — send and receive using human-readable names instead of raw addresses. Read the KNS guide.

Built-in swap

Exchange assets directly from the wallet without moving funds to a separate exchange first.

dApp connectivity

Connect the wallet to Kaspa dApps to review and sign transaction requests yourself — the dApp never has direct access to your keys.

Manage multiple wallets

Create or import several wallets and switch between them from one interface, each protected by its own locally-encrypted keys.
