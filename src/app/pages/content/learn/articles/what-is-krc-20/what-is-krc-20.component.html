What Is KRC-20? Kaspa's Token Standard Explained

KRC-20 is a fungible token standard built on top of Kaspa, letting anyone create and transfer their own tokens using Kaspa's base layer for settlement.

KAS vs. KRC-20 tokens

KAS is Kaspa's native asset — it's what secures the network and pays transaction fees. KRC-20 tokens are separate assets layered on top: they use Kaspa transactions to record token actions (like minting or transferring), but they are tracked and interpreted by KRC-20-aware infrastructure rather than by Kaspa's base protocol itself.

How KRC-20 tokens work, at a high level

KRC-20 tokens are inscribed directly into Kaspa transaction data. A dedicated indexing layer watches the chain, reads these inscriptions, and keeps track of balances and transfers for each token — similar in spirit to inscription-based token standards on other UTXO-based chains. Every KRC-20 transaction still inherits Kaspa's underlying settlement: it's confirmed by the same BlockDAG described in what is Kaspa.

Why build tokens this way instead of a separate chain?

Launching a token on Kaspa via KRC-20 means it benefits from Kaspa's existing security and block production, instead of a new project needing to bootstrap its own network and miners from scratch.

Managing KRC-20 tokens in a wallet

A Kaspa wallet that supports KRC-20 needs to talk to that indexing layer to show accurate balances and let you send or receive tokens, not just native KAS. KaspaCom Wallet handles this directly, alongside KAS, KRC-721 NFTs, and KNS domains, in one interface.
